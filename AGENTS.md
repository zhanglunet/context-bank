# 上下文银行 Agent guide

Read CONTRIBUTING.md before preparing a contribution. Publish only material the human explicitly authorized for public release. Never scan/upload a user's workspace or chat history automatically.
Use content/notes, content/workflows, skills or registry as documented. Run npm test and npm run build. Never execute scripts embedded in contributed content. Do not edit CI, trusted-author policy or permissions as part of content contributions.
Report the real pull request URL and distinguish local generation, submission, merge and verified publication.
