## 适用任务
希望让 Agent 查询已有系统，但尚不准备开放修改能力。

## 输入
公开接口说明、可授权的只读范围、脱敏数据和错误类型。

## 步骤
1. 列出查询对象、字段和分页上限，排除创建、删除、发送等动作。
2. 把接口映射为少量职责清晰的只读工具，写清参数与输出结构。
3. 补齐未授权、未找到、限流、超时等错误的处理说明。
4. 用合成数据检查权限边界；工具返回不足时提示缺失，不猜测内容。

## 合成示例
虚构工具 list_projects 只返回公开项目名称；无权限时返回明确错误，不自动切换身份。

## 提示词
根据这些接口说明设计只读 MCP 工具清单，逐项写参数、返回字段、权限、错误和限流；缺少依据处标为待确认。

## 限制
只读仍可能泄漏信息，需要字段授权与输出审查；本稿是设计方法，没有附可执行 MCP 服务。
